# Snake Game

[Play Snake](https://fulani226.github.io/snake-game/)

Original standalone HTML/CSS/JavaScript game, recovered from `snake-game.html`. The source is preserved unchanged as `index.html`.

## Controls

- Arrow keys: steer
- Space: pause/resume
- R: restart

Eat food to score, wrap around the edges, and avoid your own body. Best score is stored locally in your browser.

## Run locally

Download `index.html` and open it in a desktop browser. No dependencies or build step.

## Hosting

GitHub Pages serves the root of the `main` branch.
